# Code Diff Inspector Module

Modul **Code Diff Inspector** (`modules/diffViewer`) memberikan kemampuan inspeksi perbandingan perubahan berkas secara berdampingan (*Side-by-side Split View*) maupun linier (*Unified View*):

## Fitur Utama
1. **Split & Unified View**: Toggle antar tampilan berdampingan atau terpadu dengan penanda warna *additions* (hijau) dan *deletions* (merah).
2. **Kalkulasi Presisi**: Komputasi *diff* otomatis baris demi baris.
3. **Modal Inspector**: `DiffViewerModal` untuk menginspeksi perbedaan sebelum perubahan di-commit.
