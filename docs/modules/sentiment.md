# Sentiment Module

Modul untuk menganalisis sentimen dan nuansa emosional dari diskusi tim pada komentar GitHub Issues.

## Fitur
- **Analisis Nuansa Emosional Diskusi**: Memindai komentar issue untuk mendeteksi sentimen positif (apresiatif/solutif), kendala/kritis (bug/error blocking), dan diskusi hangat (pertanyaan/eksplorasi ide).
- **SentimentBadge Kolom Komentar**: Menampilkan indikator emosi ringkas di sebelah jumlah komentar pada setiap issue (`IssueList`).
- **Ringkasan Emosional & Rasio Diskusi**: Kartu ringkasan yang menjabarkan persentase suasana diskusi tim secara intuitif.
- **Daftar Komentar Beranotasi Emosi**: Setiap komentar tim diberi label nuansa emosional langsung.
