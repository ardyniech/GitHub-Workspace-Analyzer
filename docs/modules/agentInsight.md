# Agent Insight & Semantic Context Module

Modul **Agent Insight** (`modules/agentInsight`) menyediakan transparansi visual terhadap konteks semantik dan bobot berkas yang digunakan oleh AI Agent dalam proses pengambilan keputusan rekayasa:

## Fitur Utama
1. **File-Weighting Visualization**: Menampilkan bobot prioritas relevansi (0-100%) dan alokasi token untuk setiap berkas kunci di repositori.
2. **Context Window Allocation**: Menghitung dan memvisualisasikan total konsumsi token pada konteks aktif AI.
3. **Semantic Reasoning Overview**: Menyajikan ringkasan rasionalitas penalar AI mengenai alasan pemilihan berkas dan prioritas arsitektur.
