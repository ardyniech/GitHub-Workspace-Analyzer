# Automated Unit Test Suite Module

Modul **Automated Unit Test Suite** (`modules/unitTester`) memberikan kemampuan pengujian logika otomatis untuk memastikan kode yang dihasilkan agent teruji secara komprehensif:

## Fitur Utama
1. **Automated Test Runner**: Eksekusi pengujian otomatis untuk modul-modul selular utama.
2. **Code Coverage Tracking**: Menghitung persentase cakupan pengujian (*Code Coverage*).
3. **Interactive Test Inspector**: Modal `UnitTestModal` untuk menjalankan dan memantau status pengujian.
